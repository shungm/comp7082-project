## Overview

Budgeting application for COMP7082 course

## Features

- Feature 1: Group Dashboard for splitting group expenses
- Feature 2: Personal budgeting dashboard
- Feature 3: Scan receipt and parse receipt data
- 

## Usage Instructions

Commands to start application:
```bash
npx expo start -c
```
OR

(Use this to get application to work via BCIT school network)
```bash
npx expo start -c --tunnel
```

For OCR testing:
1. Sign up for free API Key via link: https://ocr.space/ocrapi/freekey
2. Insert API key to userReceiptScanner.ts (ie: OCR_API_KEY ='')
